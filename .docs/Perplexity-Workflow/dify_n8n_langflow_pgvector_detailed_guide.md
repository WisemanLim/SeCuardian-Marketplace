# 상세 정리: Dify+n8n, Langflow+Qdrant, 온프레미스 pgvector

## 1. Dify + n8n 조합
- Dify는 AI 애플리케이션 백엔드로서 워크플로우, 챗플로우, API 발행, 문서 기반 RAG, OpenAPI 기반 툴 연계를 제공한다.
- n8n은 승인, 재시도, 배치, 이벤트, 웹훅, 외부 시스템 통합을 담당한다.
- 권장 구조는 사용자 채널 -> Dify -> Vector DB -> n8n -> ERP/CRM/그룹웨어/메일 순이다.
- 장점: AI 로직과 업무 오케스트레이션을 분리해 운영성과 감사성을 높이기 쉽다.
- 주의점: 도구 권한, 비밀정보 관리, 승인 없는 자동 실행을 제한해야 한다.

## 2. Langflow + Qdrant
- Langflow는 Python 기반 오픈소스 AI 워크플로우 빌더이며, Qdrant 번들을 통해 벡터 읽기/쓰기를 지원한다.
- 연구개발, Python 중심 팀, 커스터마이징이 많은 조직에 적합하다.
- 장점: 코드 확장성, 모델/벡터스토어 중립성, Qdrant의 온프레미스 적합성과 결합.
- 주의점: 운영 거버넌스, 승인, 외부 연동 자동화는 별도 계층(n8n 등) 보강이 유리하다.

## 3. 온프레미스 pgvector
- PostgreSQL 중심 조직에서 가장 현실적인 출발점이다.
- 장점: 기존 DBA/백업/복구/보안 체계를 재활용 가능, 운영 도구가 성숙함.
- 한계: 대규모 ANN 성능, 고급 필터링, 벡터 전용 운영기능은 전용 벡터DB보다 제한적일 수 있다.
- 적합 시나리오: 사내 지식검색, 문서량 중소규모, 엄격한 데이터 레지던시, 낮은 운영 복잡도 선호.

## 4. 추천 기준
- 빠른 사내 포털: Dify + pgvector 또는 Dify + Qdrant
- 복잡한 시스템 연동 자동화: Dify + n8n + Qdrant/pgvector
- Python R&D 팀: Langflow + Qdrant
- 강한 데이터 표준화와 DBA 역량 보유: pgvector 우선 검토
